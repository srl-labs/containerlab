# Quickstart

Use the maintained [c9s quickstart](https://c9s.run/docs/quickstart) to create a
local Kubernetes cluster, install c9s, and deploy your first lab.

To deploy an existing containerlab topology after completing the quickstart:

```bash
containerlab --runtime c9s deploy -t topo.clab.yml
```

The [Containerlab runtime](runtime.md) guide explains the supported commands,
deployment modes, and differences from local container runtimes.
